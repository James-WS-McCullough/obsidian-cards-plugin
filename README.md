# Cards

An [Obsidian](https://obsidian.md) plugin for drag-and-drop markdown cards inside your notes. Each card holds its own markdown and lives inline among regular text — no separate view, no database.

Cards are written into a fenced ` ```cards ` block, so everything stays as plain markdown in your note and syncs like any other file.

## Features

- **Inline card stacks** — add a stack anywhere via the ribbon icon, the *Add cards* command, or the editor right-click menu. Works on desktop and mobile.
- **Full markdown per card** — each card renders its own markdown (headings, links, images, embeds). Click a card to edit it in place; click outside, press Escape, or submit to save.
- **Drag to reorder** — grab a card's handle and reorder the stack vertically.
- **Interactive tasks** — checkboxes toggle directly from the rendered card and persist back to the note.
- **Colours & highlight** — give each card a colour strip or a full background highlight, with a recent-colours palette and an OS colour picker.
- **Per-stack templates** — set the markdown each new card in a stack starts with (via the gear button).
- **Undo toasts** — deletes and reorders offer a one-tap Undo.

## Storage format

A stack is just a fenced block; cards are separated by a `---` line, and colour/highlight/template metadata is stored as invisible HTML comments so the note stays clean:

    ```cards
    <!-- cards-color: #e0533d -->
    First card's **markdown**

    ---

    - [ ] a task
    - [x] a done task
    ```

## Development

```bash
npm install
npm run dev      # watch build
npm run build    # type-check + production build
npm test         # run vitest
```

Source lives in `src/`; the build (`main.js`) is generated by esbuild.

### Deploying to a test vault

`npm run deploy` builds the plugin and copies `main.js`, `manifest.json`, and
`styles.css` into a vault's `.obsidian/plugins/cards/` folder so you can try it
live. Point it at your own vault first:

```bash
cp .env.example .env
# then edit .env and set VAULT to your vault's absolute path
```

```dotenv
VAULT=/absolute/path/to/your/ObsidianVault
```

Then:

```bash
npm run deploy
```

`.env` is gitignored, so your vault path stays local. You can also override it
inline without a `.env` file:

```bash
VAULT="/path/to/vault" npm run deploy
```

Your plugin settings (`data.json`) in the vault are never touched.
